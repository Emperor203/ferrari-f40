# Ferrari F40 LB-Works (Liberty Walk Japan) - 3D Interactive Showcase

Интерактивный 3D-шоурум легендарного суперкара **Ferrari F40** в культовом японском расширении **LB-Works (Liberty Walk)** от мастера Ватару Като (Wataru Kato).

## 🚀 Особенности и возможности
- **Высокодетализированная 3D-модель**: PBR-шейдеры кузова, карбоновый сплиттер и антикрыло, диски с глубокой полкой, тормоза Brembo, видимый через прозрачную крышку капота двигатель V8 Twin-Turbo Tipo F120A.
- **Два режима студии**: Глубокий черный премиальный шоурум (`#0a0c10`) по умолчанию + Белый чистый шоурум (`#f2f3f5`), переключение по клавише `[B]` или в меню.
- **Интерактивная оптика `[L]`**: Включение фар и фонарей с оптическими линзовыми анаморфными бликами (lens flares) и прожекторами.
- **Звук Twin-Turbo V8 `[Space]`**: Синтезатор звука перегазовки мотора до 8000 об/мин со сбросом давления турбин через блоу-офф (BOV flutter) на базе Web Audio API (без задержек и внешних файлов).
- **Кастомизация кузова**: 6 аутентичных цветов (Rosso Corsa, Bianco Fuji LBWK, Nero Daytona, Giallo Modena, Grigio Silverstone, Azzurro Dino) и 3 типа финиша (Глянец, Металлик, Матовый Сатин).
- **Пресеты камер**: 3/4 Ракурс, Профиль, Спереди, Корма / Крыло LBWK, Сверху, Двигатель Twin-Turbo.
- **Кинематографический тур `[T]`**, авто-вращение `[R]`, снимок в 4K `[P]`, режим чистого экрана Zen `[U]`.
- **Спецификации**: Выдвижная панель с полными техническими данными.

## 🛠️ Запуск локально
1. Запустите двойным кликом `start.bat`
2. Или выполните команду: `node local-server.js`
3. Откройте в браузере: `http://localhost:3000`
